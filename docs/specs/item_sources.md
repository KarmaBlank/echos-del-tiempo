# Item sources and cost grids

Status: v0.48.3 (fix/seed-icons-cost-grid).

## 1. Problem

Costs (house upgrades, helper upgrades, house placement) were plain text
("30 de oro + 2 tablas tratadas + 4 Pimientos de brasa"). Players could
not see what they already had or where to get a missing item.

## 2. Item sources (`ItemSourceRules.of(id)`)

Pure, derived only from the catalogs (no hand-kept table). One id can
have several sources; empty list = unknown (the UI says nothing).

| Item | Source |
|---|---|
| `semilla_<crop>` with `seedPrice > 0`, hoes, cans, fertilizers | `farmShop` |
| `semilla_<crop>` without price (not wild) | `forage` in the crop biome |
| Planted crop | `crop` (biome of the seed, growing seasons) |
| Wild product (`biome: silvestre` or listed in a biome's `forageKinds`) | `forage` in every biome whose forage spots give it |
| Seasonal forage (`kSeasonalForage`) | `forage` in any biome, only its season |
| Echo bloom | `forage` in hidden nooks of any biome |
| Fish | `fishing` at the lake of its biome (`zona1` = town), its seasons |
| Ore, rare | `mine` of its biome |
| Ingot | `smelting` from its ore |
| Schematic / guardian core | `dungeonVein` / `bossDrop` |
| Mining tool, supply | `smithing` |
| Trade material (fibra, cebo, tabla) | `workshop` |
| Meal | `cooking` |
| Bait | `baitCraft` |

`ItemSourceRules.owned(p, id)` counts what a player has of any of those
ids (every crop/meal quality summed).

## 3. Text

`itemSourceLines(context, id)` (features/world) turns sources into
`ui.town.source.*` lines (es-AR / en / zh-Hans). They are appended to:

- every trade item detail and hover card that sets `LifeItemDetail.itemId`
  (bag: fish, seeds, crops, trade materials);
- the cost cell tooltips (§ 4).

## 4. Cost grid

`DsCostGrid` (design molecule) shows each required item as the INVENTARIO
item cell (`DsItemCell`, 44 px) with `have/need` under it, green when
enough, red when not. Hover = `DsTooltipCard` with the item name,
"Tenés X de Y" and its source lines. `itemCostGrid(context, p, items)`
builds it from an id → amount map. Gold stays as text (it is not an item).

Used in:

- resident house upgrade (biome NPC panel, CASA cell): materials + the
  biome loot (e.g. Pimientos de brasa → "Se recolecta en Grieta");
- helper upgrades (MEJORAS);
- house placement in the CONSTRUIR palette.

The detail pane of a `LifeItemGrid` shows the grid under a REQUIERE header
(`LifeItemDetail.cost`).

## 5. Icons

Every catalog item resolves to its own sprite in
`assets/sprites/sprite_manifest.yaml` (test:
`test/features/combat/life_icon_coverage_test.dart`). Generated by
`tool/export_life_icons.dart` (crops, seeds, fish, tools, fertilizers,
meals `comida_<id>`, baits `cebo_<id>`, trade materials `mat_<id>`) and
`tool/export_mine_icons.dart` (smithing). `mat_<id>` cells of smithing
materials resolve to the smithing sprite (`GameSprites.lifeIconKeys`).
The life exporter keeps hand-written entries inside its manifest block.
