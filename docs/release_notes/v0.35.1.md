# v0.35.1

## Arreglos

- El pueblo ya no se pone lento con el tiempo: en pueblos agrandados, con varias huertas y lagos con ayudantes, el juego podía bajar a 16 cuadros por segundo y el personaje dejaba de responder. Ahora el pueblo vuelve a andar fluido a 60 cuadros por segundo aunque te quedes ahí todo lo que quieras.

## Novedades

- Pantalla "Cargando el mundo…" al tocar JUGAR, CREAR SALA o al unirte a una sala: con una barra de progreso, prepara las imágenes, las letras, los filtros y el mapa antes de dejarte entrar, así el primer paso ya sale sin tirones.

## Compatibilidad

- No cambia el protocolo de red: podés jugar con amigos que tengan la v0.35.0.
