# Ecos del Tiempo v0.20.14

## Novedad
- Las curas ahora se pueden lanzar a un enemigo. Si hay un no muerto o
  un espectro en la pelea, al elegir una cura (por ejemplo Sanación)
  elegís a quién: a tu grupo o aliado como siempre, o a ese enemigo.
  Lanzada a un no muerto le hace daño Sagrado (más que el daño de
  siempre; a un espectro, la mitad) y el menú muestra cuánto. Los demás
  enemigos no se pueden elegir.

## Multijugador
- Cambia la red (protocolo 35): jugá con quien tenga la v0.20.14.
