# v0.49.3

- Lagos gigantes:
  - Los lagos gigantes de los biomas ahora son mucho más grandes: pasan de unos 24×14 a unos 40×22 tiles de agua.
  - Hay mucho más lugar para salir en balsa y para encontrar las especies grandes.
  - La orilla siempre queda libre para caminar, así que los muelles se alcanzan sin problema.
  - Los mundos existentes regeneran sus biomas para mostrar los lagos nuevos.
  - El tamaño se puede ajustar en Balance.
