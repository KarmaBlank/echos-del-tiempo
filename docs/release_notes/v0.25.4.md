# Ecos del Tiempo v0.25.4

Arreglo rápido. Compatible con partidas y ajustes guardados.

## Pantalla
- El filtro CRT vuelve a verse: SUAVE, NORMAL y FUERTE se notan otra vez
  (desde la v0.25.0 la pantalla se veía como con el filtro apagado).

## Pueblo
- La barra de herramienta queda centrada en la pantalla; solo se corre
  si pisaría el chat o las pociones en ventanas angostas.
- Pescando, la caña se muestra como un casillero normal (ícono y
  nombre), no como un botón gris.
- Cerca de los carteles ya no aparece "[E] Leer cartel": se leen
  pasando el mouse por encima.

## Personaje
- OFICIOS: la barra de experiencia ya no se pasa del borde de la
  tarjeta.
