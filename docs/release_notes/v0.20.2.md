# Ecos del Tiempo v0.20.2

## Cambios
- **FUSIÓN, FORJA y CONDENSAR acomodables desde el Editor.** Las tres
  pantallas de la mesa ya se arman por datos: en Editor → LAYOUT se
  pueden mover sus grupos de botones y paneles.
- **La barra de la mesa ya no se desborda** con texto grande o ventana
  angosta: se apila y los materiales bajan de línea.

## Editor
- **PUBLICAR AL REPO ya no duplica el manifest.** Publicar dos veces
  dejaba una sección repetida; ahora se escribe una sola y un manifest
  ya roto se repara. Vale para layouts, efectos, sonidos y sprites.
- Al publicar un layout se conserva el comentario original del archivo.

## Multijugador
- Sin cambios de red: se puede jugar con quien tenga la v0.20.0.
