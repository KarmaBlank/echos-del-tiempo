# v0.25.7

## Cambios

- FUENTE RÚNICA más simple: un panel chico con cuatro acciones grandes, cada una con una línea que dice qué hace: EDITAR PUEBLO, CONTRATAR GRANJERO, CONTRATAR PESCADOR y TABLERO DE ENCARGOS. Si alguna no se puede usar, sale gris con el motivo.
- CONTRATAR GRANJERO cierra el panel y aleja la cámara: arriba dice "Elegí una huerta para contratar un granjero" y cada huerta muestra sus granjeros y el costo. Tocá una y listo. Las que no se pueden salen grises con el motivo (llena, falta oro o falta nivel de Cultivo). Esc cancela.
- CONTRATAR PESCADOR hace lo mismo con los lagos.
- Se fue el contador de ampliaciones de la fuente. Editando el pueblo, cuando llegás al tope las franjas salen grises con "Límite de ampliación alcanzado" (o "Límite de este lado") en vez de dejarte elegirlas.
- Se fueron los restos del ayudante viejo de la fuente.

## Compatibilidad

- Mismo protocolo de red que v0.25.5 (47): se juega junto con v0.25.5 y v0.25.6.
- Los mundos guardados siguen igual.
