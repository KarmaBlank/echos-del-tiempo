# Ecos del Tiempo v0.20.3

## Cambios
- **FORJA: las 4 mejoras a la vista.** La cuarta tarjeta (Defensa) ya no
  queda escondida abajo: entran las 4 en una fila y, si no hay lugar, se
  reparten 2 + 2.
- **Bloqueos en gris.** Los avisos de "no se puede" (como "Tope de
  forja") ya no salen en rojo: se ven en gris, como todo lo deshabilitado.
- **ATRIBUTOS sin desbordes** con ventana angosta o texto enorme: los
  valores y los botones se acomodan solos.
- **PERSONAJE acomodable desde el Editor.** En Editor → LAYOUT se pueden
  mover la barra de ATRIBUTOS y los botones del pie (REINICIAR, DESHACER,
  CONFIRMAR, CERRAR).

## Multijugador
- Sin cambios de red: se puede jugar con quien tenga la v0.20.0.
