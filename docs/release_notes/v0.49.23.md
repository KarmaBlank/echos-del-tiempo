# v0.49.23

- Cursor de acción: cuando tenés algo al lado (mata, árbol para revisar,
  parcela, roca), el recuadro verde marca justo lo que va a hacer E o el
  clic. Naranja si no se puede, con el motivo en el aviso.
- El mouse elige: pasalo por arriba de un vecino y el cursor se mueve
  ahí; el clic actúa sin que el personaje tenga que darse vuelta.
- Con teclado, la última dirección (WASD) elige el vecino de ese lado; si
  no hay nada, el más cercano.
- Los árboles se revisan desde cualquier lado, no solo de frente: se
  acabó el E que a veces no agarraba.
- Manteniendo E o el clic, al terminar uno pasa solo al siguiente.
- Con dos habitantes juntos, el que va a hablar se marca con un borde
  blanco.
