# v0.25.0

- Ajuste nuevo TEXTOS (Configuración, Accesibilidad): RESUMIDO o DETALLADO.
- RESUMIDO viene por defecto, también si ya tenías tus ajustes guardados: cada habilidad, ULT, mod, pasiva, estado y nodo de oficio se explica en una o dos líneas cortas, con el número que importa y sin fórmulas.
- DETALLADO es el texto de siempre, con números, escalado y reglas.
- En RESUMIDO, los tooltips de habilidades, armas, oficios y abonos traen MÁS DETALLE al pie para ver el texto completo de eso solo (clic o Alt).

Compatible con v0.24.x (mismo protocolo, es un ajuste local): no hace falta que tus amigos actualicen para jugar juntos, aunque se recomienda.
