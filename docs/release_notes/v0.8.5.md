# Ecos del Tiempo v0.8.5

## Menos ping jugando de a 3 o 4
- El host le mandaba a cada jugador la partida entera 15 veces por
  segundo, **con el inventario de todos**. Cada amigo que entraba la hacía
  más pesada y llenaba la subida de internet del host, así que el ping
  subía para todos, aunque cada uno tuviera buena conexión con el host.
- Ahora el perfil y el inventario de cada jugador viajan **solo cuando
  cambian**. Con 3 jugadores de inventario lleno, lo que manda el host
  baja a un tercio en una misión (15 KB → 5 KB por envío) y a casi nada
  en el lobby (10 KB → 0.5 KB).
- Con **FPS Y PING** prendido, el host anota en `ecos.log` cuánto pesa
  lo que manda.

## Arreglos
- **Materiales al tope:** con las Esquirlas (u otro material) en 99, cada
  una nueva quedaba tirada en el mapa sin poder levantarse, y todo eso
  también subía el ping. Ahora se toma igual: la pila queda en 99, lo que
  sobra se descarta y el mensaje del loot lo avisa. Nada queda en el piso.
- **El host se desconecta:** si tenías la pausa u otro menú abierto, el
  juego quedaba trabado en la pantalla DESCONECTADO sin poder hacer nada.
  Ahora cierra lo que haya abierto y vuelve al título con el motivo. Por
  las dudas, la pantalla DESCONECTADO también tiene un botón **VOLVER AL
  TÍTULO**.

## Multijugador
- **Cambio de red: todos tienen que estar en v0.8.5** para jugar juntos
  (la actualización automática se encarga). Con una versión distinta, el
  host avisa "El host usa otra versión del juego."
