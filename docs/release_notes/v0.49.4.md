# v0.49.4

- Terreno con más detalle:
  - El terreno de afuera ahora tiene el mismo nivel de detalle que las cuevas.
  - El pasto tiene matas, piedritas y flores; la tierra, terrones y grietas.
  - Los caminos muestran surco y grava, con bordes irregulares.
  - El agua tiene ondas, orilla y espuma.
  - Las montañas son más variadas: distintas formas de pico, nieve solo en algunas, cordilleras unidas y rocas al pie.
  - La tierra arada ahora tiene terrones.
