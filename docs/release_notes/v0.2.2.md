# Ecos del Tiempo v0.2.2

## Novedades
- **Filtro retro CRT, activado por defecto**: líneas de escaneo, máscara
  RGB, brillo suave, viñeta y leve curvatura, como una tele vieja. Se
  ajusta o se apaga en Pausa → PANTALLA (Apagado / Suave / Normal /
  Fuerte).
- **Opciones gráficas** en Pausa → PANTALLA:
  - Escalado: "Ajustar" (llena la ventana) o "Pixel-perfect" (escala
    entera, más nítido, con bordes negros).
  - Partículas: Baja / Media / Alta (para PCs más lentas).
  - Límite de FPS: 30 / 60 / sin límite.
- Se quitó la "velocidad de animaciones" de batalla (en grupo no
  aceleraba nada).

Compatible con la v0.2.1 para jugar en grupo (no cambió el protocolo).
