# v0.32.6

## Ayudantes

- Cuando un granjero o un pescador se traba y no tiene nada para hacer
  hasta que vos cambies algo, se queda quieto y le aparece el "!" dorado
  sobre la cabeza.
- Abrí su pantalla (G) y arriba de todo te dice por qué: "Sin semillas
  para plantar", "No hay parcelas asignadas", "El cofre está lleno",
  "Todas sus parcelas están plantadas" o "No tiene tareas prendidas".
- Si solo está esperando (que crezca lo plantado, que se seque una
  parcela, la próxima vuelta), sigue caminando como siempre y sin "!".
