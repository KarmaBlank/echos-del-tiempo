# Ecos del Tiempo v0.9.12

## Rendimiento
- **Árbol de pasivas con zoom alejado mucho más liviano:** la parte fija
  del árbol (líneas y nodos) se dibuja una vez como imagen para cada nivel
  de zoom y solo se repinta lo que cambia; arrastrar el árbol ya no lo
  redibuja entero. En las pruebas, el cuadro con todo el árbol a la vista
  pasó de ~9,6 ms a ~1,6 ms.
  - Con el zoom muy alejado, el anillo dorado de 1 px de los nodos bajo el
    mouse ya no se dibuja (a ese tamaño no se veía).
- **Minimapa** más liviano: se dibuja como una imagen en vez de tile por
  tile en cada cuadro.

## Multijugador
- Sin cambios de red: se puede jugar con quien tenga la v0.9.8 en adelante.
