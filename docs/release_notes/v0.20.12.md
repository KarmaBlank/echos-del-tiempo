# Ecos del Tiempo v0.20.12

## Arreglos
- Restaurar Quebrar. Si cambiaste el Quebrar de un arma por otra
  habilidad, en FUSIÓN ahora podés devolvérselo ("Restaurar Quebrar",
  cuesta créditos y no sacrifica armas). Si el arma tiene más
  habilidades traídas de las que entran, elegís cuál deja su lugar (se
  pierde). Solo vuelve el Quebrar propio del arma, nunca el de otro tipo.
- El mod Quebrantador ahora dice qué habilidad del arma puede quebrar
  (por ejemplo "Tajo puede quebrar"), con una línea que explica cómo la
  elige.

## Mejora
- Al traer una habilidad o una pasiva en FUSIÓN, cada una se marca
  PARA TU BUILD o NO VA CON TU BUILD según tu plan, con el motivo al
  pasar el mouse. Sin plan, no hay marcas.

## Multijugador
- Cambia la red (protocolo 34): jugá con quien tenga la v0.20.12.
