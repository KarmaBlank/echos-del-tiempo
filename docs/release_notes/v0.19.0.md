# Ecos del Tiempo v0.19.0

## BUILD v2
- **20 plantillas, 5 por clase** (una de grupo en cada una): árbol nivel a
  nivel, atributos, ULT activa con sus mejoras, hazañas y endgame.
- **Objetivos de arma:** hasta 3, con el porcentaje de avance, qué te falta y
  el plan de fusión con su costo. Mira tu inventario y el alijo compartido
  (lo del alijo aparece marcado y nunca se mueve solo).
- **Exportar e importar plantillas** a un archivo para pasárselas a amigos.
- **Filtro de botín SOLO SI MEJORA:** muestra solo lo que mejora tu build. El
  filtro Build sigue igual.
- **En la fusión** se marcan el mejor candidato y el donante sugerido, con el
  porcentaje antes y después.

## Editor (herramienta de desarrollo)
- **Animaciones ya no traba el Editor:** arranca en pausa y el resto de la
  pantalla responde mientras se reproduce.
- **Armas e ítems procedurales con perillas:** se ve el dibujo real y se
  ajustan colores, brillo, contorno, gema, proporción y más, en vivo, para
  esa entrada o para toda la familia. El juego usa esos cambios.
- Balance → Plantillas para editar las plantillas de build.

## Multijugador
- Cambia la red: todos tienen que tener la v0.19.0 para jugar juntos.
