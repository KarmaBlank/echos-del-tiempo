# Ecos del Tiempo v0.18.0

## Combate
- **Efectos nuevos con ecos** en Pulso, Instante, Fisurado, Convergencia,
  estados aplicados, aturdido, prisa y revivir.
- Las ULT de ascensión ahora también dejan ecos, con los mismos tiempos de
  antes.

## Editor (herramienta de desarrollo)
- **Línea de tiempo editable:** agregar, mover y borrar keys arrastrando,
  curvas de easing, imán, duplicar pistas, capas de ecos y deshacer/rehacer.
  Avisa si una ULT pasa de 2,6 s.
- **Todas las animaciones de batalla son datos:** golpes, habilidades,
  quiebre, Convergencias, estados, curas, escudos, muertes, apariciones y
  ULT de ascensión se pueden editar desde el Editor.

## Multijugador
- Sin cambios de red: se puede jugar con quien tenga la v0.17.0.
