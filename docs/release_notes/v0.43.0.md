# v0.43.0

## Editor de NPC
- **Todos los idiomas:** cada texto de diálogo tiene un campo por idioma del juego (español, inglés y chino). GUARDAR se bloquea mientras falte alguno. Si se agrega un idioma después, también lo pide.
- **Condición día o noche** para los temas de conversación.
- **Acciones editables:** invitar, comerciar y asignar casa se pueden ubicar como opciones del árbol, con sus condiciones. Ninguna abre quests.
- Los textos que estaban en el código (salidas nocturnas, aceptar la invitación, agradecimiento por la casa, frases sueltas) ahora se editan desde el editor.
- PROBAR permite elegir idioma y día o noche.

## Juego
- Si falta un texto en tu idioma, se muestra en español.
